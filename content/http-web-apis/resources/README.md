# HTTP & Web APIs — Complete Textbook

This ZIP contains only the `http-web-apis/` book folder, not the complete DevsLibrary project.

## Included
- `_meta.json`: topic metadata and ordered lesson index
- `CONTENTS.md`: human-readable contents
- `30 numbered Markdown lessons`: fundamentals through production design
- This reading guide

## How to study
1. Read the concepts and reproduce examples in a disposable local environment.
2. For each design exercise, write the request/response contract before implementing.
3. Test malformed input, authorization failures, timeouts, retries, duplicate requests, and dependency failures—not just happy paths.
4. Use a local or staging environment for security and load tests; never run destructive exercises against production.
5. Treat API examples as educational starting points and adapt them to your actual framework, infrastructure, and threat model.

## Quality and scope note
This is a comprehensive first edition, not a claim that every example has been executed against every server, gateway, client, or protocol implementation. HTTP behavior and security details should be checked against the versions and infrastructure in your project. The lessons emphasize contracts, failure modes, security, and operational trade-offs in addition to endpoint syntax.
