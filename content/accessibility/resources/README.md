# Web Accessibility: A Complete Practical Textbook

A standalone DevsLibrary textbook focused on practical web accessibility from fundamentals through testing, governance, and a capstone audit.

## What's included
- 38 numbered lessons in `lessons/`
- `CONTENTS.md` with the complete lesson sequence
- `_meta.json` with book metadata and learning outcomes
- Practical HTML/CSS examples, checklists, exercises, and a capstone project

## Suggested learning path
Read lessons in order, complete the exercises, and apply each topic to one real interface. Do not treat automated audit success as proof of accessibility. Combine semantic code review, keyboard testing, zoom/reflow checks, assistive-technology testing, and user research where possible.

## Standards note
This book is educational guidance, not a legal compliance guarantee. WCAG versions, browser support, assistive technology, and local legal requirements can change. Consult the current official standards and applicable policy for production decisions.
