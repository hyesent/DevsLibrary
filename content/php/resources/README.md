# PHP — Complete Textbook

This is a standalone DevsLibrary book folder, not a copy of the full project.

## Contents
- `_meta.json`: topic metadata and ordered lesson index
- `CONTENTS.md`: human-readable table of contents
- `45 numbered Markdown lessons`: foundations through production practice

## Recommended study method
1. Read the lesson and type out the examples.
2. Run code in a supported PHP environment; verify your installed version with `php -v`.
3. Complete the practice tasks before reading ahead.
4. For database, upload, authentication, and deployment exercises, use a local disposable environment and never expose secrets.
5. Add tests for every important behavior and failure case.

## Compatibility note
The book uses modern PHP features in examples, including features that require recent PHP 8.x releases. Check each feature against your project's minimum supported version before adopting it. Runtime and extension requirements depend on the specific exercise.

## Quality note
This book is a broad first edition. Examples are teaching examples, not a substitute for project-specific security review, and have not all been executed across every PHP version or operating system.
