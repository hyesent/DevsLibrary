# Linux — DevsLibrary textbook

This is a standalone DevsLibrary book folder, not the full project. Copy the `linux/` folder into `DevsLibrary/content/` to add it to a compatible checkout.

## How to study

1. Work in a disposable lab directory and use a non-administrative account for routine practice.
2. Read the explanation, predict the command's effect, run it, then inspect the result.
3. Never run a destructive or privileged command on a production machine just to follow an example.
4. Check your distribution's installed manual pages; commands and options vary.
5. Complete the practice task and write down evidence, not just conclusions.

## Safety note

Commands are examples, not a substitute for checking your operating system, permissions, paths, and operational context. Examples that change files are intended for a personal sandbox. Firewall, disk, bootloader, service, privilege, and filesystem-repair changes require a recovery plan.
